# <img src="https://cdn.jsdelivr.net/gh/devicons/devicon/icons/python/python-original.svg" width="32"/> Python Learning

Repositório criado para documentar minha jornada de aprendizado em **Python**, reunindo exercícios, desafios, experimentos e pequenos projetos desenvolvidos durante os estudos.

A ideia é transformar o aprendizado em prática, começando pelos fundamentos da linguagem e evoluindo gradualmente para projetos mais completos.

##   Objetivo

Este repositório tem como objetivos:

* Aprender Python na prática;
* Desenvolver lógica de programação;
* Praticar resolução de problemas;
* Aprender boas práticas de programação;
* Criar pequenos projetos;
* Registrar minha evolução ao longo dos estudos;
* Construir uma base para projetos maiores no futuro.
